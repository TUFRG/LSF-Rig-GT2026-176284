# LSF-Rig-GT2026-176284

This repository contains openly available CAD files, engineering drawings, analyses, and bills of materials associated with the Low-Speed Fan Rig (LSF) facility at the University of Windsor.

## Citation

If you use the materials contained in this repository, please cite the following paper, which details the design and calibration of the rig:

> Thomson, A., Chiodo, M., Fontanin, L., and Defoe, J., “Design of a Low-Speed Fan Rig for Measuring Response to Inlet Flow Distortion,” *Proceedings of the ASME Turbo Expo*, GT2026-176284, Milan, Italy, June 15–19, 2026.

## Important

Due to file upload size limitations, not all files could be included directly in this repository. Additional files can be accessed using the external link provided here: https://tufrg002.ecs.uwindsor.ca/index.php/s/4SxddGqZcooCFn8 

To ensure the CAD assemblies function correctly, download the missing CAD files from the shared link and place them in their corresponding folders according to the directory structure provided. Failure to do so may result in missing references when opening product or assembly files.

## Repository Contents

The repository is organized into four main folders:

### Latest Assembly

This folder contains the most recent assembly of the Low-Speed Fan Rig, provided as an `Assembly.CATProduct` file.

The CAD models were created using CATIA V5-6R2021. All associated part files required for the assembly are stored within this folder.

### Engineering Drawings

This folder contains the technical drawings for components of the rig that required machining or fabrication.

### BOM

This folder contains the bill of materials (BOM), including purchase orders and receipts for the components procured for the rig.

### Analyses

This folder contains the engineering analyses that informed the design decisions made during the development of the Low-Speed Fan Rig. Analyses were conducted using a combination of CATIA V5 R6-2021 and Ansys Mechanical
